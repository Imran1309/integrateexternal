🔒 Security & API Integration Overview

Welcome to the API security laboratory. This dashboard demonstrates three critical pillars of production-grade software development:

1. OAuth 2.0 Auth Protocol

Learn security standards using the Authorization Code Grant Flow with Refresh Tokens. Authenticate securely, acquire scoped access tokens, and access protected resources.

2. External API Gateway

Observe proxy forwarding, request scrubbing, and memory caching mechanisms that decrease external API load (Open-Meteo & GitHub APIs) and improve latency.

3. Rate Limiting & Chaos Monkey

Examine server protection via client IP rate limits (standard headers returned) and handle API failures gracefully through real-time interceptors.
